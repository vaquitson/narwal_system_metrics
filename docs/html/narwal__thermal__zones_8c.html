Detailed Description

Internal implementation of the Narwal Thermal Zones interface.

This file contains the internal functions used to enumerate and read thermal zones exposed by the Linux thermal subsystem.

int narwal_thermal_zones_fill_by_type ( NarwalThermalZone * tz_p,
const char * type_str_p )

Retrieve the thermal zone corresponding to the provided type string.

Retrieve the thermal zone corresponding to the provided type string. This function clears the structure pointed to by "tz_p", so it is safe to use with a previously initialized thermal zone.

In case of an error, a negative value is returned indicating the error. The contents of the thermal zone pointed to by "tz_p" may be left in an undefined state.

Parameters
tz_pPointer to the structure where the thermal zone information will be stored.
type_str_pString containing the type name of the thermal zone.
Returns
An event code. If the returned value is negative, an error has occurred.
Return values
NARWAL_THERMAL_ZONES_SUCCESSThe thermal zone structure was filled successfully.
NARWAL_THERMAL_ZONES_NULL_PTREither "tz_p" or "type_str_p" is NULL.
NARWAL_THERMAL_ZONES_OPEN_ERRAn error occurred while trying to open the thermal zone directory /sys/class/thermal/.
NARWAL_THERMAL_ZONES_READ_ERRAn error occurred while trying to read the type file of a thermal zone.

◆ narwal_thermal_zones_get_type()

char * narwal_thermal_zones_get_type ( NarwalThermalZone * tz_p)

Return the type name of the provided thermal zone.

Return the type name of the thermal zone pointed to by "tz_p".

On a successful call, this function returns a pointer to the type string stored in the provided thermal zone structure.

If an error occurs, NULL is returned and the "error" field of the structure pointed to by "tz_p" is set with the corresponding error code.

Parameters
tz_pPointer to the thermal zone whose type will be retrieved.
Returns
A pointer to the thermal zone type string on success, or NULL if an error occurs.

int priv_narwal_thermal_zones_fill_next ( NarwalThermalZone * tz_p,
unsigned int opts )

Retrieves the next available thermal zone.

On each successful call, this function clears the structure pointed to by tz_p and fills it with information about the next thermal zone available in the system.

Successive calls iterate through the thermal zones exposed under "/sys/class/thermal/".

When no more thermal zones are available, the function returns NARWAL_THERMAL_ZONES_NO_MORE_TZ and rewinds the internal directory iterator so that the next call starts again from the first thermal zone.

when starting a new search for a specific thermal zone.

Parameters
[out]tz_pPointer to the structure in which the thermal-zone information will be stored. The structure is cleared before being filled.
[in]optsIteration options.

The opts parameter controls the iteration behavior:

  • opts == PRIV_NARWAL_THERMAL_ZONES_OPT_NO_REWIND: Continue from the current iterator position.
  • opts == PRIV_NARWAL_THERMAL_ZONES_OPT_REWIND: Rewind the directory iterator before searching. This is useful
Returns
A Narwal Thermal Zones status code. Negative values indicate errors.
Return values
NARWAL_THERMAL_ZONES_SUCCESSA thermal zone was retrieved successfully and tz_p was filled.
NARWAL_THERMAL_ZONES_NO_MORE_TZNo more thermal zones are available. The internal iterator was rewound.
NARWAL_THERMAL_ZONES_OPEN_ERRThe /sys/class/thermal/ directory could not be opened.
